# Romantic Background Music 🎵

The background music file for the website is stored here:
`public/audio/romantic-bgm.mp3`

### How to replace with your favorite romantic song:
1. Choose any romantic MP3 song you love (like Tum Hi Ho, Kesariya, a romantic flute/piano instrumental, etc.).
2. Rename your file to:
   **`romantic-bgm.mp3`**
3. Copy and paste it right into this folder (`public/audio/`), replacing the existing file.
4. Refresh the website — your new song will automatically play smoothly with loop and volume controls!
